## 🛠 技术说明

- **零依赖**：每个实验都是单文件 HTML，内联 CSS + 原生 JS，不打包、不构建、不联网加载外部库。
- **打开即跑**：双击 `index.html` 也能在本地浏览器里完整运行。
- **适合阅读**：所有可视化用原生 SVG 画，不依赖任何图表库，加载即秒开。
